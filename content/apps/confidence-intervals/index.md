# Confidence Intervals Explorer

This applet helps you understand how confidence intervals behave across different sample sizes and confidence levels.

## Features

- Adjust sample size and see how interval width changes
- Change confidence level (90%, 95%, 99%)
- Visualize coverage rates across multiple samples
- Interactive parameter controls
