# Hypothesis Testing Lab

An interactive exploration of hypothesis testing concepts, p-values, and statistical power.

## What You'll Learn

- How null and alternative hypotheses work
- The meaning of p-values in context
- Type I and Type II error rates
- Statistical power and effect size

## Interactive Features

- Drag sliders to change effect size
- Adjust sample size to see power changes
- Visualize rejection regions
- Compare different significance levels

Perfect for understanding the logic behind statistical inference!
